# NetOne · 北科大校园网监测

Windows 桌面端校园网监测工具（PySide6），针对**北京科技大学**校园网：
流量额度实时监控 + 多目标网络延迟监测，二合一。

> 面向北京科技大学校园网环境开发：额度数据来自门户首页与 ePortal 接口，
> 计费参数（免费额度 / 单价 / 计费流量口径）均可在设置中按实际情况调整。

## 功能

**校园网额度**（主页面）
- 本月剩余额度环形图、已用/日预算进度条
- 近 30 天日用量柱状图（超预算染红 + 预算虚线）、当月每日热力图
- 6 个指标卡：今日用量 / 近 7 日日均 / 预测月底 / 账户余额 / IPv6 免费流量 / 口径差值
- 在线终端管理：查看当前账号在线设备，重命名、信任、强制下线
- 额度告警：阈值提醒、用量突增、月底预测、余额不足（Windows 原生通知）

**网络延迟**
- 多目标实时 RTT 曲线、丢包率、抖动、整体评级
- 直连 / 经代理识别、网络诊断、导出 CSV
- 目标可自定义，内置常用站点模板

**悬浮窗与托盘**
- 置顶半透明悬浮窗：额度环 + 延迟行，逐项开关、紧凑模式、锁定、透明度
- 托盘图标即额度环，一眼看出剩余额度；关窗收进托盘，后台继续监测
- 单实例：重复双击只会把已有实例的主面板抬到前台

**日志**：独立标签页汇总丢包、延迟尖峰、额度告警与设置变更。

## 额度口径

学校有三个地方能看到用量，口径并不一致：

| 来源 | 字段 | 说明 |
|---|---|---|
| 门户首页内嵌 JS 变量 | `flow`（KB） | 滞后/次级口径，偏小 |
| ePortal `visitor/loadUserFlow` | `v4`（MB） | 与自助服务权威账本一致 |

本程序**主指标用 `v4`**，实测中它从不小于 `flow`（扣额度落在保守一侧）。
接口取不到时自动退回 `flow` 兜底，界面上的来源徽章会从「接口口径」换成
「门户口径」明示，不拿兜底值冒充权威值；页脚小字标出口径差值。

## 运行

需要 Windows 10/11 + Python 3.12+：

```bat
python -m venv venv
venv\Scripts\pip install -r requirements.txt
venv\Scripts\python app.py
```

## 打包

```bat
venv\Scripts\python -m PyInstaller --noconfirm --clean NetOne.spec
```

产物为**散文件夹** `dist\NetOne\`（onedir，启动比单文件快；不引入 QtCharts，
只依赖 PySide6-Essentials，体积小几十 MB）。注意不要在旧 `dist\` 上原地覆盖重打包。

## 数据文件

全部生成在**程序所在目录的 `data\` 子文件夹**，整个文件夹拷走即完成迁移，
不写注册表：

| 文件 | 内容 |
|---|---|
| `config.json` | 目标、界面、校园网、提醒、设备等全部设置 |
| `netone.db` | 额度快照、日汇总、设备别名与信任标记 |
| `netone.log` | 最新一份日志，记事本直接打开可查错 |
| `latency_history.json` | 退出时自动保存的延迟历史 |
| `logs\netone-*.tar.gz` | 轮转归档的旧日志（超 1 MB 压缩，最多 5 份） |

装到不可写的位置（如 `Program Files`）时自动退回 `%APPDATA%\NetOne\data`；
可用环境变量 `NETONE_HOME` 指定运行目录。
